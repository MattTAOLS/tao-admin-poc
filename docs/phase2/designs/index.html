TAO Admin POC · Phase 2

Phase 2 designs

Static mockups of every new or changed page, built from the portal's own design tokens and components. Nothing here is live code. Each page carries numbered design notes; reply with the design ID and note number to change something, for example "D6 note 4: drop the industry average line".

Decisions already locked

  • TAO Admin is the manager. It edits extracted values and covenants and manages users. TAO Analyst stays read-only and can comment. On the partner side, Company Admin manages its own team.
  • Trend colour shows good or bad for that metric; the arrow shows direction. Delinquency rising is red, coverage rising is green.
  • Edits before publish are free (audited, rules re-run). After publish, an edit is a correction: new version, re-published, partners notified.
  • Extraction does not change. Sharper page images come from rendering, not from reading the PDF differently.
