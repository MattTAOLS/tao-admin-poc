Audit log

Changed
Everything that happens to a report, and every change to the platform. This month first; earlier months under History.
1The log is split into two tabs. Reports: upload, extract, re-extract, override, restatement accepted, value edited (new), correction (new), approve, reject, publish, comment (new). Platform: covenant change (new), user change (new), role change (new), settings change (new), master data, regenerate. Every entry belongs to exactly one tab. Only TAO Admin sees this page (as today, route /admin/settings/users/audit).
2Search looks through every month and both tabs at once: deal name, person, action, field name, before and after values, reason, comment text and upload id. Results replace the month view (see the "Essex" state further down). The three filters (action, user, deal) narrow the current month, each History month and search results alike, and live in the URL so a filtered view can be bookmarked or linked. The Audit link on an upload still opens this page filtered to that one upload, across all months.
