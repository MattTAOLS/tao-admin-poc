10News feed. One run each morning at 06:00 ET pulls items that mention the company name or its aliases; each item shows source, time, a sentiment word (Positive, Neutral, Negative, never colour alone) and a link out. “News this week” on D5 counts these. Partners see the same feed. All items here are placeholders, not real reports about this company.
11Adverse media. Daily screening across five categories: litigation, regulatory, fraud, insolvency, sanctions. New hits arrive as Open. Only TAO Admin marks an item Reviewed (with a note) or Dismissed (with a reason, e.g. different entity); TAO Analyst can comment. Every state change is audited. Partners see the status word and Reviewed items; Open and Dismissed items are TAO only, so a false name match never reaches a partner (open question 4).
